About me

关于我

一名把「找 Bug」当成推理过程的技术学生。

我是钟嘉伟，江西软件职业技术大学区块链技术专业 2027 届本科生。 从大二接触软件测试开始，我逐渐意识到：测试不是点点点，而是用有限的用例覆盖无限的可能性。 所以我更愿意先拆需求、画测试点，再动手设计用例。

在 P2P 借贷系统的测试实践中，我用等价类、边界值、场景法设计了 60+ 条用例， 用 Postman 校验 20+ 个核心接口，再用 MySQL 多表关联核对用户、标的、订单与流水表的金额一致性， 定位过「状态流转与流水不匹配」这类靠界面根本看不出来的问题。

自动化方面，我用 Python + Selenium + pytest + Allure 搭了一套 POM 分层 + 数据驱动的 UI 测试框架，把 ECSHOP 电商后台的登录回归从人工点击压缩到分钟级。 日常也习惯用 Fiddler / Charles 抓包、看 Linux 日志、写 SQL，先自己判断问题归属前端还是后端，再提单给开发。

这个站点是我记录测试实践的地方 —— 包括踩过的坑、定位问题的思路，以及一些可复用的脚本。 如果你也在做测试，欢迎交流。
